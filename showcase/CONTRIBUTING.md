# Contributing

Short version: **corrections yes, features no.**

This repository is an architecture showcase. It contains prose, diagrams, and
fabricated sample data. There is no application here, no build, no test suite,
and no roadmap of work to pick up — the AgentiCubed implementation is private and
is not published.

## What is welcome

Open an issue for any of these, and thank you:

- A factual error in the documentation
- A broken link, a diagram that does not render, a typo that changes meaning
- An architectural claim you think is wrong — genuinely welcome, and the most
  useful thing anyone can file here
- A licensing or attribution problem
- Anything in this repository that looks like it should not be public

If you think something here is a security or privacy problem, please **do not**
open a public issue. Use one of the direct contact routes in the
[README](README.md#connect-at-ai4) instead. Note that this repository contains no
running system and no source code, so there is nothing here to exploit — but if
something in it should not be public, that is worth telling me privately.

## What will be closed

Pull requests adding features, tooling, CI, dependencies, or code. GitHub does
not allow pull requests to be disabled, so this line is the policy: they will be
closed with thanks rather than reviewed. There is no codebase here for them to
change.

Small documentation fixes as pull requests are fine if that is easier for you
than an issue.

## No support commitment

There is no SLA, no support organization, and no vulnerability disclosure
programme behind this repository. It is one person's public writeup of a private
system. Issues are read, and answered when there is something useful to say.
